*2026 International Conference on Multimedia Analysis and Pattern Recognition (MAPR 2026)*  
**First author:** Tien Nhu Dinh · Co-authors: Thang Cap Pham Dinh, Phung Do

- Led the research and implementation end to end, combining **Swin Transformer image features**, an **MLP-based metadata encoder**, and **Bayesian Semantic Data Augmentation (BSDA)** in feature space.

### 2. [Vietnamese Traffic Sign Detection](https://github.com/nhudinhtien-4w/Vietnamese-Traffic-Signs-Detection)
**Individual project · Python · PyTorch · Faster R-CNN · ResNet50-FPN · Flask**

- Fine-tuned an object detector for **52 Vietnamese traffic sign categories**, covering annotation parsing, data validation, checkpoint selection, and evaluation.
- Created a Flask inference API and interactive demo to upload road images and visualize bounding boxes, labels, and confidence scores.
- **Reported evaluation:** **92.6% precision** and **94.6% recall** on **639 test images** at **IoU ≥ 0.50** and **confidence ≥ 0.30**.
